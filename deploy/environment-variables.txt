ROSHNI SOLAR DEPLOYMENT VARIABLE REFERENCE
==========================================

Set these values in your hosting provider's secret/environment-variable panel.
For a conventional Node server, place the same values in a local .env file that
is never committed to Git.

NODE_ENV=production
PORT=3000
DATABASE_URL=mysql://DB_USER:DB_PASSWORD@DB_HOST:3306/roshni_solar_quotation
JWT_SECRET=replace-with-a-long-random-secret-at-least-32-characters
VITE_QUOTATION_ASSET_BASE=/assets/roshni-quotation

OPTIONAL MANUS ORGANISATION SIGN-IN VARIABLES
VITE_APP_ID=
OAUTH_SERVER_URL=
OWNER_OPEN_ID=

OPTIONAL MANUS STORAGE-PROXY VARIABLES
BUILT_IN_FORGE_API_URL=
BUILT_IN_FORGE_API_KEY=

Never share production values or commit them to a repository.
