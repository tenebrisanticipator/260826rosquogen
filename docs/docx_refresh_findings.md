# Roshni Solar Source Template Notes

The quotation source uses a branded masthead, cloud background, system diagram, yellow-highlighted technical and commercial tables, distributor footer, payback analysis, terms, bank details, seal, product-components sheet, warranty/protection sheet, and installation collage. These visual assets are included in the external handover bundle at `client/public/assets/roshni-quotation/`.

The dynamic proposal calculates plant size from panel wattage and panel count, applies Indian currency formatting, and composes project-specific pricing, subsidy, payback, technical specifications, and customer information into the branded quotation sequence.
